# Blitz Warfare - Fast-Paced PvP & Action Combat for Factorio

**Blitz Warfare** превращает Factorio в динамичную соревновательную Action-RTS стратегию (2v2, 1v1v1v1 или FFA) с фокусом на боёвку с первых минут, активные скиллы и осаду баз.

---

## ⚡ Ключевые особенности

### 1. Боевая система и активные способности (WASD + хоткеи)
* **Рывок (Combat Dash)** (`SHIFT + SPACE`) — резкий рывок в сторону движения персонажа для уклонения от снарядов и разрыва дистанции.
* **Энергетический барьер (Energy Barrier)** (`V`) — кратковременный щит, поглощающий входящий урон в критический момент перестрелки.
* **Нано-турель (Deployable Nano-Turret)** (`X`) — мгновенный сброс временной боевой турели прямо посреди файта.

### 2. Ранний арсенал вооружения
* **Боевой дробовик (Combat Shotgun):** смертоносный в упор с эффектом отбрасывания противников.
* **Тактическая штурмовая винтовка (Tactical Rifle):** высокий темп стрельбы и бронебойные патроны.
* **ЭМИ-гранатомёт (EMP Launcher):** временно отключает вражеские турели и энергощиты перед штурмом базы.
* **Тесла-карабин (Tesla Carbine):** выпускает цепные молнии, поражающие несколько целей.

### 3. Сессионный PvP-формат (20–40 минут)
* **Главный штаб (Command Core):** у каждой команды есть база-ядро. Уничтожение вражеского штаба приносит победу.
* **Ускоренная экономика:** компактное боевое древо технологий без лишнего гринда.
* **Борьба за центр:** в центре карты расположены ценные месторождения и аванпосты для мотивации ранних стычек.

## 📁 Структура проекта

```
blitz-warfare/
├── info.json                 # Манифест мода (Factorio 2.0 / 1.1)
├── data.lua                  # Точка входа этапа данных (прототипы)
├── control.lua               # Скрипты во время игры (скиллы, матчмейкинг, PvP)
├── settings.lua              # Настройки мода в интерфейсе игры
├── locale/
│   ├── ru/strings.cfg        # Русская локализация
│   └── en/strings.cfg        # Английская локализация
├── prototypes/
│   ├── custom-input.lua      # Регистрация горячих клавиш (Dash, Shield, Turret)
│   ├── weapons.lua           # Новые пушки ранней и средней игры
│   ├── ammo.lua              # Патроны, гранаты, ЭМИ-заряды
│   ├── entities.lua          # Нано-турели, Командный Штаб
│   ├── recipes.lua           # Рецепты крафта для быстрого темпа
│   └── technology.lua        # Компактное военное древо технологий
└── scripts/
    ├── skills.lua            # Логика работы скиллов и кулдаунов
    ├── pvp.lua               # Управление командами (forces), спавны, победа
    └── gui.lua               # Интерфейс кулдаунов и состояния матча
```

## 🚀 Установка для разработки

Символическая ссылка в папку модов Factorio на macOS:

```bash
ln -s "$HOME/Documents/GitHub/blitz-warfare" "$HOME/Library/Application Support/factorio/mods/blitz-warfare"
```
